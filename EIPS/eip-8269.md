## Abstract

Include the well-known Arachnid deterministic deployment proxy (a small `CREATE2` factory at `0x4e59b44847b379578588920cA78FbF26c0B4956C`) in chain genesis, so the same factory is available at the same address on every chain. This lets contracts be deployed at identical addresses across chains.

## Motivation

Applications want their contracts at the same address on every chain. `CREATE2` gives deterministic addresses, but only relative to the deploying contract, so you first need a factory that itself sits at the same address everywhere. That factory already exists on Ethereum and most chains; this EIP guarantees it on all of them by putting it in genesis.

## Specification

* `FACTORY_ADDRESS` = `0x4e59b44847b379578588920cA78FbF26c0B4956C`

A chain's genesis state includes `FACTORY_ADDRESS` with nonce `1` and this runtime code:

```
0x7fffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffe03601600081602082378035828234f58015156039578182fd5b8082525050506014600cf3
```

This is the Arachnid deterministic deployment proxy: called with a 32-byte salt followed by init code, it runs `CREATE2` ([EIP-1014](./eip-1014.md)) with that salt, that init code, and the call value, and returns the new 20-byte address.

## Rationale

* **No-op for mainnet and most chains.** The factory was bootstrapped long ago via a keyless transaction and already sits at this address on Ethereum mainnet and most other chains, so including it changes nothing there; it only matters for chains that lack it.
* **Reuse, don't reinvent.** This is the de-facto standard `CREATE2` factory and the default in common tooling, so enshrining the existing one keeps every chain and tool compatible. An alternative, [EIP-7997](./eip-7997.md), instead adds a new factory in the precompile range.

## Backwards Compatibility

On chains that already have the factory (Ethereum mainnet and most others), this is a no-op. No other contract is expected at the address.

## Security Considerations

Contracts whose init code reads the environment (`ORIGIN`, `NUMBER`, etc.) can be frontrun, since the factory does not tie deployments to the caller. Use it only for fully deterministic contracts.
