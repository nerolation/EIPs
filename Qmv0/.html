How it works

Each quantum identity pre-generates a pool of one-time Lamport keypairs (256 secret/public bit-pairs each, derived deterministically from a seed). The public halves are hashed into per-keypair commitments, which are leaves of a binary Merkle tree — the tree root is the reusable quantum address. To send a transaction, one unused leaf is consumed: the 256-bit message hash is signed by revealing one secret per bit, producing a signature that is provably unforgeable without the private pool, and independently verifiable against the public Merkle root via an inclusion proof. This mirrors the same "many-time from one-time" trick used by stateful hash-based post-quantum schemes (XMSS/SPHINCS+), implemented from scratch in C++, Python, and JavaScript here, and projected onto Ethereum, Solana, Pi Network, and Stellar/Soroban via pluggable chain adapters.
